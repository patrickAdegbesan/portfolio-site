About

The developer
behind the code

Hi, I'm Patrick.

I'm a full-stack and AI engineer based in Lagos, Nigeria, building at 3O1Atech and independently. I work at the point where AI systems meet real infrastructure — the part where a clever prototype has to become something that runs on its own.

My work spans multi-agent LLM systems and reinforcement learning through to production platforms in Python, TypeScript and React. I've built a fourteen-agent LLM system with a provider-agnostic backend, an ensemble RL system carried across seven milestones to unattended deployment, and an AI fraud-detection product delivered under hackathon pressure.

What I care about most is the layer people skip: the runbook, the alerting that surfaces signal instead of noise, the promotion gate that refuses a worse model, the audit trail behind every automated decision. Anyone can ship a demo. I'm interested in what happens on day ninety.

I work AI-native — Claude Code is my daily build tool, and this site is maintained through it. When a task repeats, I turn it into a script. When a system is worth keeping, I document it properly.
